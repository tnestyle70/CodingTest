# 트럭 Visual Studio 따라쓰기 준비 계획

2026-10-11 Asia/Seoul

- 실제 솔루션 `코딩테스트/코딩테스트.slnx`의 편집 프로젝트에 `스택과큐\다리를지나는트럭` 필터를 추가한다.
- 저장된 사용자 풀이와 참고 풀이는 기존 파일을 상대경로로 연결하고, 새 `다리를지나는트럭_따라쓰기.cpp`에는 빈 solution 틀을 둔다.
- 세 solution 소스는 VS 편집 프로젝트에서 빌드 제외하여 중복 정의를 방지한다. 별도 Debugging 프로젝트의 실행 대상은 유지한다.
- CMake의 기존 solution-only OBJECT 예외에 따라쓰기 파일을 추가한다. XML·파일 경로·빌드 제외 여부를 확인하고 Debug/Release 빌드를 수행한다.
- Visual Studio에서 솔루션을 열고, 학습 문서 및 이번 준비 변경을 GitHub main에 동기화한다. 다른 작업의 미추적 파일은 포함하지 않는다.
