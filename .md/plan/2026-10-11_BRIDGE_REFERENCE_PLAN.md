# 트럭 전체 참고 풀이 계획

2026-10-11 Asia/Seoul

- 사용자가 전체 풀이와 정석 코드를 명시적으로 요청했으므로 퇴장 시각 큐를 이용하는 전체 참고 풀이를 제공한다.
- 사용자 코드와 답변은 보존한다. 참고 코드와 별도 main 검증 파일을 추가하며 기존 프로젝트의 빌드 설정은 변경하지 않는다.
- 현재 매초 시뮬레이션에서 퇴장 시각으로 이동하는 방법을 유도하고, 불필요한 대기 큐·완료 개수를 줄인 이유를 설명한다.
- C++17로 컴파일해 공식 예제, 경계값, 작은 입력 전체 조합을 독립적인 다리 칸 시뮬레이터와 대조한다. 최대 입력은 독립적인 기대식으로 확인한다.
- 시간 O(N), 보조 큐 공간 O(min(N,L)), 입력 복사 포함 O(N)의 근거를 설명한다. 코치가 제공·검증한 참고 풀이와 학습자 성과를 구분한다.
