Session - 프로그래머스 고득점 Kit 47문제 AC와 실전 해석 능력 확보
현재 위치 (2026-10-07 확인): 전체 5/47 AC, 해시 5/5 AC, 다음 문제는 같은 숫자는 싫어. 이후 진도는 [tracker](../records/HIGH_SCORE_KIT_TRACKER.md)를 따른다.

현재 연습 과제: 직접적인 기준선 생성, 복잡도 합산, 코딩 전 정확성 설명, 자작 반례. 실행 방법은 [코딩테스트 가이드](../../코딩테스트_가이드.txt)에 정리한다.

## 1. Decision Record

① 문제·제약: 이 로드맵은 고득점 Kit 10개 유형 47문제를 대상으로 시작했다. 초기 수립 당시 AC 증거는 0개였으며 현재 진도는 상단과 tracker를 따른다. 전부 순서대로만 풀면 쉬운 문제 반복이 천장 훈련을 밀어낼 수 있다.
② 순진한 해법의 실패: 해설을 읽고 코드를 베끼면 체크 수는 늘지만 처음 보는 지문에서 알고리즘을 선택하는 능력을 측정하지 못한다.
③ 메커니즘: 유형별 개념 1회, 기본 문제 AC, 변형 문제 AC, 제한 시간 천장 문제, 지연 복습 순환으로 운영한다.
④ 대조: 47문제 완주만 최적화하지 않고 매주 30%는 아직 못 푸는 난이도와 상위 풀이 해부에 고정한다.
⑤ 대가: 진도표 완료 속도는 느려질 수 있다. 실전 제한 시간 성과가 오르지 않으면 유형별 정독 비중을 줄이고 모의 테스트 비중을 높인다.

## 2. Completion Gates

- Kit Completion: 47/47 실제 AC
- Explanation: 각 문제의 복잡도와 불변식을 말로 설명
- Recall: 핵심 문제를 24시간 이상 뒤에 다시 구현
- Transfer: 각 유형에서 Kit 밖 변형 문제 최소 1개 AC
- Mock: 제한 시간 모의 테스트에서 목표 점수 반복 달성

## 3. Session Shape

- 10분: 지문 재서술과 제약 표시
- 15분: 완전탐색 기준선과 복잡도 판결
- 25분: 사용자 구현
- 10분: 로컬 반례와 수정
- 제출 후: AC/실패 원인 기록
- 24시간 이후: 핵심 아이디어 백지 복원
