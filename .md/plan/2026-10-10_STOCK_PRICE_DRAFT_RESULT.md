# 주식가격 독립 풀이 준비 — RESULT

- 전달받은 코드와 주석은 [참고본](../10-10/references/주식가격.cpp)에 보존했다. 줄 끝 공백만 정리했다.
- [작성본](../../코딩테스트/주식가격.cpp)은 solution 시그니처와 빈 answer 반환만 남겼다. 자료구조 선택이나 풀이 힌트는 넣지 않았다.
- 사용자는 참고 코드를 아직 읽지 않았다고 밝혔다. 참고본은 사용자 독립 풀이 또는 AC로 기록하지 않는다.
- VS 편집 프로젝트의 스택과큐 필터에 추가하고 빌드 제외로 등록했다. 기존 디버깅 프로젝트는 유지했다.
- CMake에는 main이 필요 없는 OBJECT 타깃으로 등록했다. 주식가격 실행 파일과 디버깅 하네스는 아직 없으므로 `Run-CurrentProblem.ps1 -Problem 주식가격`의 실행 대상은 아니다.
- 확인: 프로젝트·필터 XML 파싱 및 등록 검사, 작성본에 구현이 없는지 검사, `git diff --check` 통과.
- Debug/Release 빌드는 모두 `cmake` 명령을 찾지 못해 컴파일 전에 중단됐다. 컴파일·실행·프로그래머스 채점 성공은 확인하지 않았다.
- 작성본만 편집 패널 열기를 요청했다. 참고본은 열지 않았다.
