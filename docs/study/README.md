## 첫 학습 순서

1. 개념서의 1~7절로 입출력·상태·스택·큐의 관계를 읽는다.
2. 질문집의 첫 진입 경로에서 한 질문씩 답한다. 답을 만들기 전에 해설을 다시 읽지 않는다.
3. 공식 Kit의 첫 문제를 읽고 목표와 기준선을 자기 말로 설명한다.
4. 코딩 전에 상태·갱신·종료·정확성·비용을 말한다.
5. 직접 구현하고 Build·Example·Edge·Judge 결과를 기록한다.
6. 하루 이상 뒤에는 코드 없이 복원하고 조건을 바꾼 질문에 답한다.

질문집 전체를 끝내야 실전으로 이동하는 것은 아니다. 현재 문제에서 막힌 지점을 찾아 해당 질문으로 돌아간다. 수업에서는 질문 하나 → 사용자 답변 → 근거와 반례 점검 → 다음 질문으로 진행한다.

## 자료와 학습 상태

2026-10-07에 GitHub 저장소의 main 커밋 `aad83d6e22cfa5a65566c85c8b31043422901839`를 데스크탑 작업 폴더에 복제했다. 그 시점의 원격에는 C++ 풀이 파일들이 있으며, 이 학습 자료는 이후 로컬에서 추가했다.

2026-10-10에는 main을 `10192d9`까지 fast-forward 동기화하여 기존 `.md` 학습 문서와 운영 규칙도 받아왔다. 질문의 정본은 [.md의 검문소 문서](../../.md/concepts/CHECKPOINT_QUESTIONS.md)이며, 여기의 자료는 그 틀을 적용하는 설명·작성 예시·출력 연습이다.

기존 코드 파일의 존재를 현재의 독립 풀이 능력이나 채점 통과 기록으로 간주하지 않는다. 2026-10-10에는 사용자가 새로 작성한 오른쪽 비교 버전의 Judge 100.0점 보고를 확인했다. [작성 예시](SAME_NUMBER_WALKTHROUGH.md)를 이 AC 코드 기준으로 갱신했다. 로컬 C++ 실행과 지연 복원 성과는 아직 확인하지 않았다. 진행 증거는 [문제 회고](../../problems/stack_queue/12906_같은_숫자는_싫어/REVIEW.md)와 [세션 기록](../../.md/records/2026-10-10_STACK_QUEUE_SESSION.md)을 따른다.

원문은 제공된 내용을 그대로 보존한 텍스트다. 원문의 상대 링크를 따라 읽을 때는 기존 [통합 사고 과정 Markdown](../../.md/concepts/2026-10-02_UNIFIED_PROBLEM_SOLVING.md)을 사용한다. 작성과 출력 연습에는 위 가이드와 질문집을 사용한다.
