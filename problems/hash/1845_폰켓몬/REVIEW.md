## Interpretation

- 한 문장 목표: N마리 중 안 겹치는 종류 N/2만큼 추려서, 고를 수 있는 종류 수의 최댓값을 return (사용자 선서술)
- 입력 크기: nums 길이 N ≤ 10,000 (항상 짝수). 종류 번호 ≤ 200,000은 값의 범위 — 루프 횟수·set 크기와 무관 (이번 세션 핵심 교정 지점)
- 중복·순서·범위 조건: 같은 종류 중복 선택 합법, 순서 무관
- 요구되는 출력: 최대 종류 수 (int)

## Complexity Budget

- 완전탐색: N/2마리 고르는 모든 조합 C(N, N/2) 열거 — C(20,10)=184,756, N=10⁴이면 예산 밖 → 죽음 (판결 문장 사용자 보완 대기)
- 목표 시간 복잡도: O(N log N) — set 삽입 10⁴ × log₂(10⁴)≈13 ≈ 1.3×10⁵ 연산 → 13×10⁻⁴초 ≈ 0.0013초 → 통과 (사용자 산술, X012 슬립 교정 후)
- 목표 공간 복잡도: O(k) — k = 존재하는 종류 수 ≤ N

## Approach

- 핵심 관찰: 조합을 열거할 필요가 없다 — 답은 종류 수 k 하나로 결정된다. 병목 = 중복 제거(종류 세기)
- 자료구조/알고리즘: set (레드블랙 트리, 삽입 O(log N)). unordered_set 평균 O(1)도 가능하나 N=10⁴라 둘 다 예산 내 — 선택 근거 비교는 사용자 보완
- 불변식 (사용자 선서술, 승인본): 답 = min(k, N/2). 마리당 최대 1종류이므로 N/2마리로는 N/2종류를 넘을 수 없고, 서로 다른 종류가 k개뿐이므로 k를 넘을 수 없다. 달성: k ≥ N/2이면 서로 다른 종류로 N/2마리를 채우고(각 종류 최소 1마리 존재), k < N/2이면 k종류를 하나씩 담고 남는 N/2−k자리는 이미 담은 종류와 겹치는 마리로 채운다 — 이 채움은 종류 수를 떨어뜨리지 않으며, 남은 마리 N−k ≥ N/2−k (⟸ N ≥ N/2)이므로 항상 충분하다. set은 k를 세는 도구다.
